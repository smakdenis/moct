# МОСТ

Прочитай [порядок авторства, передачи и разбора](references/MOST.md). Выполняй оба авторских этапа в текущей модели за один ход. В одном финальном ответе дай готовый блок задания, рекомендацию и действие для пользователя. Здесь отвечай на языке запроса. Для сложной задачи используй [ориентиры по видам результата](references/implementation-handoff.md).

МОСТ поддерживает три среды. По умолчанию выбирай подходящую модель из доступных в текущей среде. Если человек выбирает между средами, сравни доступные варианты из этой тройки по возможностям задачи и сопоставимым единицам оплаты. Учитывай список именно этой учётной записи и актуальные официальные условия. У подписки, API и локального тарифа могут быть разные единицы. При неизвестной цене назови необходимую возможность и что известно о расходе. Любая передача начинается отдельным действием пользователя.

- **DeepSeek Harness.** Используй список моделей текущего профиля Harness. Предложи пользователю выбрать модель чата в интерфейсе и отправить «продолжай». При передаче сюда из другой среды достаточно открыть чат Harness, вставить готовый блок и приложить перечисленные материалы.
- **Kimi.** В Kimi Code список и выбор модели текущей сессии доступны через `/model`. Новый запрос к навыку можно начать с `/skill:most`. В обычном чате Kimi пользователь может вставить готовый блок с вложениями.
- **Codex.** Для авторства в Codex есть нативный навык `$most:make-prompt`. Для реализации достаточно вставить блок в чат на выбранной модели. При продолжении в том же чате Codex может проверить выбранную модель через свой доверенный обработчик.

В DeepSeek Harness и Kimi пауза действует как инструкция автору. Удостовериться в переключении можно по сведениям клиента или явному подтверждению пользователя. Не запускай подчинённую модель и не инициируй запрос в другую среду за пользователя.

## Поправки для следующих задач

Если доступен Python, перед новым промптом прочитай подходящие правила с помощью `python3 scripts/lessons.py list --scope data` из каталога этого навыка. Области — `data`, `code`, `interface`, `writing`, `visual`, `other`, `general`. Применяй проверку только при совпадении условия. Новая инструкция пользователя важнее записи. Если данных нет, продолжай работу.

После фактической проверки помоги отделить упущение в задании от ошибки исполнителя или отсутствующего инструмента. По просьбе «запомни для похожих задач» сохрани короткие поля `when` и `check` через UTF-8 JSON на stdin команды `python3 scripts/lessons.py save --scope data`. Назови полученный ID. Для просмотра есть `list`, для удаления конкретного правила по просьбе человека — `forget ID`. На одном компьютере три среды могут читать общий пользовательский файл `~/.most/lessons.sqlite3`, когда у них есть доступ. На другом устройстве или в чате без файлов передай одобренное правило текстом.
