# МОСТ

МОСТ работает в **Codex, DeepSeek Harness и Kimi Code**. Выбранная вами модель за один ход придумывает замысел и превращает его в технический промпт. В конце ответа она рекомендует исполнителя и ждёт, пока вы переключите модель или перенесёте задание в другое приложение.

## Первый запрос

| Где вы работаете | Что написать |
| --- | --- |
| Codex | `Сделай промпт для …` или `$most:make-prompt Сделай промпт для …` |
| DeepSeek Harness | `/most Сделай промпт для …` |
| Kimi Code | `/skill:most Сделай промпт для …` |

Например, **«Сделай промпт для каталога выездной библиотеки. У книги может быть ноль экземпляров, а иногда остаток неизвестен. Читатель должен видеть разницу»**. Укажите формат результата и нужные вложения. Назовите среду исполнения, если хотите перейти в одну из двух других.

В том же чате выберите рекомендованную модель и напишите **«продолжай»**. В Kimi Code селектор открывается командой `/model`. При переходе между приложениями откройте новый чат у исполнителя, вставьте целиком блок задания и приложите названные файлы. Для обычного приложения Kimi это и есть способ передачи. Нативная команда `/skill:most` относится к Kimi Code. [Команды Kimi Code](https://moonshotai.github.io/kimi-code/en/reference/slash-commands.html)

Если выбранная модель уже совпадает с рекомендованной и вы хотите продолжить в ней, напишите **«продолжай в текущей модели»**. Во время проверки Luna предложила выбрать саму себя. Сверка названия в селекторе и эта явная команда решают такой случай.

## Как выбор влияет на лимиты

Автор расходует лимит выбранной авторской модели. Реализация и её проверка расходуют лимит модели, в которой вы их запустили. Если весь чат продолжает работу на Astra, её координация тоже расходует лимит. Для экономии заканчивайте авторский ход на готовом промпте и переключайте весь чат. При разных провайдерах действует тариф соответствующего аккаунта.

МОСТ учитывает инструменты, сложность задачи, видимые модели и сопоставимые цены. В Codex он запрашивает текущий каталог, учитывает дату кэша и поддерживаемый уровень рассуждения. В DeepSeek Harness важны модели выбранного профиля, в Kimi Code — модели текущей сессии. Если сведений о личном тарифе не хватает, рекомендация указывает основание выбора и неизвестную часть стоимости. [Модели Codex](https://learn.chatgpt.com/docs/models?surface=app) · [Тарифы Codex](https://learn.chatgpt.com/docs/pricing)

## Как МОСТ учитывает ошибки

Если результат разошёлся с промптом, попросите **«Разбери, где пришлось додумывать»**. МОСТ проверит, какого требования не хватало, какое уже было записано и какие проверки оказались недоступны. Исправление для следующих задач можно сохранить явной просьбой.

> Запомни в МОСТ для задач с данными. Когда пропуск и нулевой остаток имеют разный смысл, включай в приёмку два примера. В одном ожидается число 0, во втором — null.

При следующей похожей задаче модель сможет включить эту проверку в промпт. Запись хранится в личном файле `~/.most/lessons.sqlite3` и содержит область, условие и проверку. Три приложения на одном компьютере читают один профиль при наличии разрешений и Python. Команды **«Покажи правила МОСТ»** и **«Забудь правило с ID …»** дают контроль над ним. Для другого устройства или обычного чата Kimi скопируйте нужное правило вместе с заданием. Автоматической отправки в общий архив пользователей нет.

## Установка из архива

Распакуйте архив и откройте терминал в папке `most`, где лежит этот README. Для Codex используйте штатный менеджер плагинов или `install.command` на macOS.

```bash
codex plugin marketplace add "$PWD" --json
codex plugin add most@most --json
```

При первой установке нативных обработчиков откройте Review hooks в Codex или `/hooks` в его CLI. Подтвердите оба обработчика МОСТ. В версии 1.2.0 один распознаёт запрос и продолжение, второй один раз проверяет полноту финальной передачи. Если повторно устанавливаются только навыки Harness или Kimi, эти действия в Codex не требуются.

Для DeepSeek Harness и Kimi Code нужен Python 3. В Windows команду `python3` может заменять `py -3`. Запустите строку для нужной среды.

```bash
python3 install_skill.py deepseek
python3 install_skill.py kimi
```

Установщик кладёт навык `most` в `skills/` внутри `DSH_HOME` или `KIMI_CODE_HOME`. Обычно это `~/.dsh/skills/most` и `~/.kimi-code/skills/most`. Для установки только в одном проекте добавьте `--project /путь/к/проекту`. Уже установленная идентичная копия распознаётся. При совпадении имени с другим содержимым установщик сообщит путь к конфликту. Откройте новую сессию клиента для проверки команды. [Навыки DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness/blob/master/docs/subsystems/skills.md) · [Навыки Kimi Code](https://github.com/MoonshotAI/kimi-code/blob/main/docs/en/customization/skills.md)

## Что означает пауза

В Codex доверенный обработчик может заблокировать типовое «продолжай» на прежней модели ещё до нового модельного хода. Для этого нужна сохранённая отметка о предыдущем запросе в том же чате. Она содержит идентификатор модели, время и признак «только промпт». Имя файла образовано из хеша идентификатора чата. Отметка действует до семи дней и очищается после постороннего запроса. При запрете записи, пропуске обработчика или другой формулировке проверка может не сработать. Для двухэтапного сценария первым запросом попросите подготовить промпт. В Harness и Kimi автор завершает ответ по инструкции, а пользователь выбирает следующий чат.

В комплекте есть [переносимый текст для чата Kimi](plugins/most/skills/make-prompt/references/MOST.md) и [отчёт о проверках](VERIFICATION.md). Проверки пакета запускаются командой `python3 -B -m unittest discover -s tests -v`. Все три среды используют собственный чат. [Apps SDK UI](https://github.com/openai/apps-sdk-ui)
