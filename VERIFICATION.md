# Проверка МОСТ

18 ноября 2026 года проверены Codex, DeepSeek Harness и Kimi Code на macOS. Навыки установлены в пользовательских каталогах этого компьютера.

| Среда | Что проверено |
| --- | --- |
| Codex | Штатный App Server вернул включённый `most:make-prompt` версии **1.2.0**. События `UserPromptSubmit` и `Stop` одновременно показали `enabled` и `trusted`. Файлы нативного модуля совпали с установленной копией. |
| DeepSeek Harness **0.2.2-rc.3** | Файловый загрузчик из установленного приложения обнаружил `most` в категории `user-dsh`, разрешил вызов пользователем и моделью, прочитал тело навыка и его каталог ресурсов. Путь совпал с `~/.dsh/skills/most`. В интерфейсе Harness команда навыка имеет вид `/most`. |
| Kimi Code **2.3.3** | В новой сессии клиент вернул `skill:most` через Agent Client Protocol. Затем `/skill:most` с тестовым заданием в изолированном профиле передал локальному тестовому серверу тело навыка, путь к инструкции и аргумент пользователя. Клиент получил ответ. |

В Harness проверено чтение каталога и тела навыка. В Kimi проверен также интерактивный путь через ACP. В отдельной пробе `kimi -p` передал строку с командой без раскрытия навыка, поэтому для явного вызова в инструкции указан интерактивный чат. Качество ответа их удалённых моделей на данном компьютере отдельно не измерялось. В обычном приложении Kimi предусмотрена ручная передача блока с вложениями. ## Живой запрос в Codex

Экономичная GPT-6-Luna Low получила через обычный `codex exec` просьбу подготовить промпт для файла `result.json`. У книги A числовой остаток 0, у книги B остаток неизвестен. Модель прочитала установленный МОСТ, его переносимую инструкцию, профиль правил и каталог моделей. В **финальном** сообщении были один копируемый промпт, значения `0` и `null`, проверка типов, рекомендация модели и короткая причина. Стоимость при неизвестном тарифе модель обозначила как неизвестную. После ответа тестовая папка оставалась пустой.

Luna порекомендовала уже выбранную Luna и попросила выбрать её ещё раз. Для этого случая в обработчике предусмотрено явное **«продолжай в текущей модели»**. Прямой тест подтвердил, что обычное «продолжай» на прежней модели блокируется, явная команда разрешается, а при другом идентификаторе модели отметка удаляется. Переключение пользователем в графическом интерфейсе во время этого запуска не выполнялось. В более раннем тесте совмещённая просьба о промпте и немедленной реализации приводила к созданию файла автором, поэтому наиболее предсказуемый первый запрос — «сделай промпт».

## Повторное применение поправки

В отдельном временном профиле проверен пример с неизвестным остатком. Контрольные данные с `B = 0` провалили критерий неизвестного значения. С помощью установленного модуля Kimi сохранено правило различать ноль и `null`. Установленные модули DeepSeek Harness и Codex прочитали его для задач с данными. Для задачи на текст правило не выдавалось. В следующее примерное задание добавлена извлечённая проверка. Контрольные данные с `A = 0` и `B = null` прошли оба критерия. Удаление по ID из Harness убрало правило из всех трёх представлений. Для этой проверки использовались тестовые входы и ожидаемые значения. Личный профиль пользователя остался вне теста.

Прошли **35 автоматических тестов**. Они покрывают распознавание запросов, смену модели, доступность и возраст каталога, остановку, внешнюю передачу, одновременную установку, защиту пользовательских правок, область действия правила, повторную запись и удаление. Оба файла `SKILL.md` прошли валидатор. Синтаксис `install.command` проверен.

## Предыдущий живой пример Astra → Terra

В проверке 17 ноября авторский ход выполнила выбранная GPT-6 Astra Max. Готовый промпт без редактирования передан задаче с выбранной GPT-6.1 Terra Extra High. Terra создала «Атлас тихих мест». В браузере прошли по 106 проверок на ширинах 1440 и 390 пикселей. Сохранены тексты, бумажная палитра, указатель и логика фильтров. Полный проход стрелками по нативным выпадающим спискам остался непроверенным. Этот пример относится к версии 1.0.0. Выбранную модель исполнителя подтверждают метаданные задачи.
