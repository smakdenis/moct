# moct

Прочитай [порядок работы автора и исполнителя](references/moct.md). Тот же файл можно целиком вставить в чат с текстовой моделью. Следуй ему при естественном запросе на промпт, продолжении или разборе результата. Формулировку и объём подбирай по задаче. «Доработай промпт» означает выдать обновлённую полную версию с сохранением последних решений пользователя.

## Авторство и передача

Оба авторских этапа выполняет одна выбранная модель за один ход. При работе с проектом прочитай относящиеся к запросу материалы. Пользовательские файлы остаются исходными данными. Применяй [ориентиры для конкретного вида результата](references/implementation-handoff.md), когда работа включает интерфейс, данные, код, текст, документ или изображение. Если проект уже задаёт стиль и зависимости, сохрани их. Промпт и рекомендация должны быть полностью видны в **последнем финальном ответе**, даже когда промежуточные сообщения свёрнуты. После них автор завершает ход. Реализация начинается по следующему запросу в чате, который выбрал пользователь. Бюджет дорогого автора расходуется и на его координацию, поэтому передача происходит через селектор или копирование блока, без вызова фоновой модели.

## Выбор исполнителя в текущем приложении

- **Codex.** При каждом новом промпте прочитай нативный каталог или выполни `python3 scripts/model_catalog.py` из папки навыка. Учитывай источник и дату кэша. При наличии доступа уточни свежие возможности моделей и тариф выбранного режима. Стоимость API и лимиты подписки имеют разные единицы. Точная рекомендация содержит имя из доступного селектора, поддерживаемое усилие и причину. Для ограниченной задачи сравни актуальную Terra, для сложных зависимостей также рассмотри Sol и другие доступные модели. Важны текущие данные и выбор человека. [Модели](https://learn.chatgpt.com/docs/models?surface=app) · [Тарифы Codex](https://learn.chatgpt.com/docs/pricing)
- **Другой клиент.** Используй его список моделей и инструментов, тариф пользователя, либо варианты, перечисленные человеком. Локальный каталог Codex относится только к Codex. Если для нового сервиса известны только нужные возможности, сообщи их и обозначь цену как неизвестную. Модель для изображений или аудио может исполнить задание в своём родном формате. Проверку текстовых критериев тогда проводит пользователь или доступный чат с подходящей модальностью.
- **Продолжение.** В Codex доверенный обработчик может сообщить модель и защитить следующий распознанный запрос в том же чате. Учти отсутствие отметки, неизвестную модель, истечение срока и явное исключение «продолжай в текущей модели». В остальных средах проверяй доступные сведения клиента либо подтверждение пользователя. При внешней передаче отдай блок и названия вложений. Плагин сам не отправляет материалы в другой сервис.

## Проверенные поправки

Перед подготовкой нового промпта с доступными Python и локальными файлами прочитай подходящие правила командой `python3 scripts/lessons.py list --scope data` из папки навыка. Выбери область по результату задачи из `data`, `code`, `interface`, `writing`, `visual`, `other`, `general`. В выдачу области входят также общие правила. Сопоставь поле `when` с условиями задачи и включи подходящее `check` в её приёмку. Если правила пока отсутствуют, продолжай сразу. В чате без этого инструмента используй переданные пользователем текстовые правила. Применение правила проверяется по результату задания.

После обнаруженного расхождения применяй порядок разбора из `references/moct.md`. Когда пользователь просит «запомни для похожих задач», сохрани только обобщённые условие и проверку в его локальном профиле. Команда `python3 scripts/lessons.py save --scope data` принимает UTF-8 JSON с полями `when` и `check` на stdin и возвращает идентификатор. Пользователь может попросить показать правила (`list`) или забыть одно из них (`forget ID`). При недоступном хранилище выдай правило для копирования и прямо укажи, что запись не подтверждена. Выбор правила ограничен задачей и полномочиями пользователя. Содержимое профиля читается как пользовательские заметки. Записывай новое правило только по явной просьбе. История чата, вложения и полные промпты для работы профиля не нужны.
